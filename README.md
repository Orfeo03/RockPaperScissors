# Rock Paper Scissors Game

A simple Rock Paper Scissors game I built using Python while practicing the basics of programming.

The player chooses rock, paper, or scissors, and the computer randomly picks one of the three options. The game compares both choices and tells the player whether they won, lost, or tied.

 Features
- Play against the computer
- Random computer choices
- Win, lose, and tie results
- Option to play multiple rounds
- Runs in the terminal

 Technologies Used
- Python
- Random module
